# D&D 5e Schnellreferenz

Eine deutsche Schnellreferenz für D&D 5e: Bewegung, Aktionen, Bonusaktionen, Reaktionen, Zustände und Umgebungseffekte. Ein Klick auf eine Kachel öffnet die Details.

**Live:** https://darthhose.github.io/dnd5e-quickref/

Die Seite besteht nur aus einer Datei (`index.html`). Sie braucht keinen Build und keine Installation und funktioniert auch offline, abgesehen von den Schriftarten (Google Fonts).

## Quellen und Lizenzen

- **Original:** Diese Seite ist eine deutsche Nachbildung von [crobi/dnd5e-quickref](https://github.com/crobi/dnd5e-quickref) von Robert Autenrieth, Layout und Code stehen unter der MIT-Lizenz (siehe `LICENSE.md`).

- **Schriftarten:** Noto Sans und Lora über Google Fonts (SIL Open Font License).
- **Regelinhalte:** Die Texte folgen den Grundregeln von Dungeons & Dragons, 5. Edition (Spielerhandbuch). Maße sind metrisch angegeben (5 ft = 1,5 m). Verweise nennen Kapitel statt Seitenzahlen.

## Selbst veröffentlichen

1. Repository forken oder die Dateien in ein eigenes Repository hochladen.
2. Unter *Settings → Pages* den Branch `main` und den Ordner `/ (root)` auswählen.
3. Nach ein bis zwei Minuten ist die Seite unter `https://darthhose.github.io/dnd5e-quickref/` erreichbar.
